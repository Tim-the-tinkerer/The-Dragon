# Security

Dragonfold rearranges samples. It does not hide them.

Anyone who has the file can play every sample that was in the recording. They are all still there. A person who knows the phrase, the unit, the grain, and the pass count can put them back with this app. The phrase is a fast hash. A short or common phrase can be guessed.

The fold note records that a phrase was used. It does not record the phrase. A wrong phrase still writes audio. That audio is not the recording.

This is not a lock, and it is not a substitute for FileVault. Do not use it to protect a private recording.

The original file is not overwritten. Export asks for a new path, and that path is refused when it is the file you opened.
