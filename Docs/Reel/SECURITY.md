# Security

Dragonreel rearranges frames, and the sound that belongs to those frames. It does not hide them.

Anyone who has the file can watch every frame and hear every sample that was in the movie. They are all still there. A person who knows the phrase, the axis, the tile, the run, and the pass count can put them back with this app. The phrase is a fast hash. A short or common phrase can be guessed.

The fold note records that a phrase was used. It does not record the phrase. A wrong phrase still writes a movie. That movie is not the original.

This is not a lock, and it is not a substitute for FileVault. Do not use it to protect a private movie.

The original file is not overwritten. Export asks for a new path, and that path is refused when it is the file you opened.

The movie is H.264, and the sound is AAC. A restored file is the frames and the samples in their earlier order, with the change the codecs made when the scrambled movie was written.
