# Security

The Dragon is four rearrangements in one window. None of them is a lock.

The phrase is not written into the file. Someone who has the file can try phrases. A wrong phrase still produces output, and that output is not the original. The same phrase and the same settings put a marked fold back.

Curve, Scale, Fold, and Reel each describe their own limits:

- `Docs/Curve/SECURITY.md`
- `Docs/Scale/SECURITY.md`
- `Docs/Fold/SECURITY.md`
- `Docs/Reel/SECURITY.md`

This is not a substitute for FileVault.
